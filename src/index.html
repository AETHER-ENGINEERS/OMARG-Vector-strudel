How a room works

  1. Each person taps Play once. That arms their speaker. Audio never leaves the device.
  2. Code travels. Sound does not. Everyone renders the same pattern locally.
  3. Eval to room (or Ctrl/Cmd+Enter) sends the editor to everyone who already tapped Play.
  4. live hot-swaps as you type (220ms). Friends hear it after Eval, or live if the pulse lands.
  5. Stop (Ctrl/Cmd+.) hushes this device and tells the room you paused.

Stay in one scale for family jams. Default is A minor pentatonic: a c e g. Swap those letters and it still sings.

Vector has no AudioWorklet. Prefer sawtooth, piano, and drums. supersaw and room() often throw here.

Mini-notation

bd*4
Play bd four times in one cycle.
~
Rest. Silence that slot.
[a1 c2]
Subdivide. Two notes in the time of one.
One per cycle, rotating.
"hh*8"/2
Twice as slow.
$:
A layer. Stack as many as you want.
s("bd")
Which sound. Drums, piano, sawtooth…
note("a3")
Pitch. Letter + octave.
slider(0.5, 0, 1)
Number you can drag under the editor.
setcpm(140/4)
140 BPM if a cycle is 4 beats.
.gain(0.4)
Volume 0–1. Keep leads quiet.
.lpf(800)
Low-pass filter. Smaller = darker.
